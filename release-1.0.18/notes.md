- Для каждой версии WarMind скачивается один ZIP со всеми доступными локализациями.
- Если выбранной локализации нет, лаунчер запускает английскую из установленного мода. Настройка языка сохраняется.
- Обновлены подписи на русском и английском, в том числе для установок, получающих автообновление.

Для установки с нуля распакуйте WarMind-Launcher-win64.zip. Установленный лаунчер получит новую версию через автообновление.

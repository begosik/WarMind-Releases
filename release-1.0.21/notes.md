- ZIP мода, BIG лобби и DLL скачиваются параллельно.
- Большие ZIP с Google Drive загружаются несколькими частями одновременно, если сервер поддерживает диапазоны.
- Во время загрузки можно закрыть лаунчер через крестик. После подтверждения окно сразу закрывается, загрузка отменяется, временные файлы очищаются.

Для установки с нуля распакуйте WarMind-Launcher-win64.zip. Установленный лаунчер получит новую версию через автообновление.

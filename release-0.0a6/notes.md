## Изменения

- Добавлен модуль отражения урона `YurikoShieldSphereUpdate` и схемы для его использования в RA3 Mod Studio. Модуль можно подключать к юнитам через их XML.
- Исправлено сохранение разрешённых фракций, дохода с шахт и личного автовыбора. Настройки хозяина сетевой игры и одиночного «Сражения» сохраняются отдельно.
- Включены последние исправления локализации из исходников WarMind.

Для установки выберите канал «Тестовая» в WarMind Launcher.
